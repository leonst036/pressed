# Pressed
## A game like Lemon stand but in the fish shell

## Setting up
Just run the file `press.fish`.

## How to play
Your goal is to earn as much money as possible by selling lemonade

Each day you can:

1. Buy lemon seeds or lemons from the market
2. Plant seeds for the next day
3. Press lemons into lemonade
4. Sell lemonade to customers
5. React to changing weather conditions

## Tech stack
Completly written in fish
